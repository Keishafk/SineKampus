# SineKampus

A basic mobile app for exploring short films created by BSCS 3C Group 1. SineKampus allows users to browse student films, search for movies, view movie details, and save their favorite films.

Built with **React Native** and **Expo** as a beginner-friendly project for learning React Native fundamentals.

> **Status:** Early development. Core screens and UI are being built first. Advanced features such as a backend, user accounts, and video streaming are not included yet.

---

## Features

### Planned / In Development

* **Home screen** — browse featured and recent student films
* **Movie cards** — display posters, titles, genres, and release years
* **Movie details** — view information about a selected film
* **Search** — search for student films by title
* **Favorites** — save films to a personal favorites list
* **Student films** — showcase short films created by university students
* **Filter** - filter films by genre, year, and department

### Future Features

* User profiles
* Video playback
* Online movie database
* User authentication
